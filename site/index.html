One app, every kind of compare

Drop two things on the window. PCompare picks the right viewer.

Text, folders, spreadsheets, images, binaries, registry keys, executables, audio tags and live databases, plus merge, sync and review tools around them.

Text Compare

Editable side-by-side diff with word-level highlights, Patience or Myers, ignore rules for whitespace, case and regex-defined text. Saves with the original encoding, BOM and line endings.

Text Merge

2- or 3-way merge against a common ancestor. Non-conflicting changes merge automatically; take left, right, both or base per conflict. Works as a git mergetool.

Folder Compare

Parallel recursive scans that stream rows in as they are found. Quick tests by size and timestamp, then binary, CRC-32 or rules-based content compare.

Folder Sync

Update, mirror or two-way sync with history. Every copy and delete is previewed, journaled and reversible.

Folder Merge

3-way merge of whole folder trees: changes, additions, deletions and conflicts each get a proposed action, and text conflicts open in Text Merge.

Table Compare

Cell-by-cell CSV/TSV, Excel and ODS workbooks and HTML tables. Align rows on key columns, ignore columns, set a numeric tolerance.

Picture Compare

PNG, JPEG, GIF, BMP, TIFF, WebP and more. Side-by-side, difference, blend and swipe views with per-channel tolerance and synced zoom.

Hex Compare

Streams files of any size, aligns inserted bytes and jumps straight to the next differing block.

Database Compare

Schema and data compare for SQL Server, MySQL/MariaDB, PostgreSQL and SQLite. Pick changes with arrows and review them in plain English.

Registry Compare

.reg exports (REGEDIT4 and v5) or live keys such as HKLM\Software\Vendor, value by value.

Version Compare

Version resources of .exe and .dll files plus PE facts: architecture, timestamp, ASLR/DEP/CFG and signatures.

MP3 Compare

ID3, APE, Vorbis and MP4 tags of MP3, FLAC, M4A, OGG/Opus, WAV and AIFF, with audio properties and cover art.

Text Edit

Edit a single file with syntax colours, find & replace, bookmarks, encodings and line endings.

Patch Viewer

Browse a .patch or .diff file by file, then apply it to a folder and compare the result.

Comparison Archive

Save a comparison with its bookmarks and comments as a .pcmpz and hand it to a reviewer, read-only.

Documents too

Word (.docx, .doc), OpenDocument, RTF and PDF are converted to text and compared like any other file. Zip, tar and 7z open as folders.

Folder Sync

Sync that's afraid of losing your files

Every sync shows a preview of each copy, delete and new folder, with a checkbox per item and per-row overrides. Then the executor treats your data like it's the only copy.

  • Pre-flight checks for free space, write access and nested folders, and a warning before mirroring from an empty (unmounted?) folder.
  • Atomic copies flushed to disk and swapped into place, with optional read-back checksum verification.
  • Never overwrites surprises. Files changed since the preview are left alone; sources modified mid-copy are retried.
  • Locked files are retried with backoff, then deferred, skipped or stop the run. On Windows the report names the program holding the file.
  • Journaled runs. Resume or roll back after a crash, retry failed items, or undo a finished sync. Deleted files go to the Recycle Bin, Trash or a versioning folder.
  • Two-way with history. Deletions propagate; edits on both sides become conflicts you settle by rule: skip, newer wins, left or right wins.

Sync Automation

Set it once. Get told when it breaks.

Turn any folder sync into a task that runs on its own from the system tray, starting quietly with your computer.

  • Triggers: daily or weekday schedules, every N minutes, cron expressions, at startup, or real-time when files change.
  • Safety policies abort a run that would delete most of a folder, and catch up on missed runs.
  • Alerts to Microsoft Teams, Slack, email (SMTP), webhooks or the desktop, with secrets kept in the OS keychain.
  • Run history with retries, conflicts, bytes copied and the full message for every failure.

Database Compare

Command line & scripting

Built for scripts, hooks and CI

PCompare speaks the common compare-tool switches, script language and exit codes, so existing CI jobs, hooks and nightly scripts run unchanged.

  • pcompare @nightly.txt runs compare scripts headlessly: load, filter, select, compare, sync, reports, snapshots and more.
  • /qc quick compare and /automerge merge without opening a window.
  • One click sets PCompare up as git's difftool and mergetool, with --wait. Snippets for Mercurial, Perforce and Subversion.
  • Import saved sessions from other compare and sync tools.
Terminal
# compare two folders, or a past revision
$ pcompare ./site ./backup
$ pcompare git:src/app.rs@HEAD~3 src/app.rs

# CI: did anything really change?
$ pcompare /qc=rules build/ expected/
rules-based same: only line endings differ
$ echo $?
2

# 3-way merge, open only the conflicts
$ pcompare "$LOCAL" "$REMOTE" "$BASE" "$MERGED" \
    /automerge /reviewconflicts

# run a compare script, no window
$ pcompare @nightly.txt "D:/work" "E:/backup"
